# Zahlenblick

Statistik zu den Eurojackpot-Ziehungen: alle Ziehungen, Kombinationen, Diagramme, das Taktik-Labor und ein
KI-Assistent, der Fragen zu den Zahlen beantwortet.

**Download-Seite:** [thechickenmc.github.io/zahlenblick](https://thechickenmc.github.io/zahlenblick/)

| Gerät | So geht's |
|---|---|
| **Windows** | [EuroJackpot.exe](https://github.com/TheChickenMC/eurojackpot/releases/latest/download/EuroJackpot.exe) herunterladen und starten – keine Installation nötig |
| **Android** | [EuroJackpot.apk](https://github.com/TheChickenMC/eurojackpot/releases/latest/download/EuroJackpot.apk) herunterladen und installieren |

Updates kommen von selbst. In diesem Projekt liegen die fertigen Programme (unter „Releases“), nicht der Quelltext.

Zahlenblick ist ein Statistik-Programm und kein Glücksspiel: Man kann damit nicht tippen und nichts gewinnen.
Statistiken beschreiben die Vergangenheit – sie sagen keine Lottozahlen voraus und ändern nichts an der Gewinnchance.
Zahlenblick ist ein unabhängiges Angebot und steht in keiner Verbindung zu Eurojackpot oder den Lotteriegesellschaften.
